Post Studio - Privacy policy

Last updated: 24 October 2026

Post Studio is a personal desktop tool made and used by Julian Green to publish his own videos. This policy explains what it does with account data.

Data it accesses

When the account owner connects an account, Post Studio asks for permission to:

  • YouTube (Google account): upload videos; read and change the titles, descriptions, tags, visibility and schedule of the channel's own videos; read the channel's own view counts and watch time (YouTube Analytics, read-only).
  • TikTok: read the account's basic profile (name) and upload videos to the account's drafts.

How it is used

Only to upload, schedule and edit the account owner's own videos, and to show the owner how those videos are doing. Nothing else.

Where it is stored

Everything stays on the computer Post Studio runs on: the sign-in tokens, the posting queue and the video details. There is no Post Studio server. Data is sent only to YouTube or TikTok themselves, to carry out what the owner asked for.

Sharing

Post Studio does not sell, share, transfer or disclose any user data to anyone, does not use it for advertising, and does not use it to train AI models.

Post Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

  • Remove Google access at myaccount.google.com/permissions.
  • Remove TikTok access in the TikTok app: Settings and privacy > Security > Manage app permissions.
  • Delete all locally stored data by deleting the Post Studio folder in %LOCALAPPDATA%.
